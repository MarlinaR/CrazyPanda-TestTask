# Test Assignment: CrazyPanda, Techincal Artist Position

## Task Description

The goal of this test assignment was to:  
- Transfer a scene from Photoshop to Unity. Change Photoshop where it needs to be imported and used correctly.  
- Create a responsive UI with proper handling of safe zones.  
- Implement particle effects and other visual effects to enhance the scene.  
- Add parallax effects for a sense of depth and dynamism.  
- Optimize the final solution performance.  

This assignment aimed to demonstrate skills in UI development, visual effects, optimization, and integration between design tools and game engines.

## Result

The final result includes a fully functional and visually appealing scene implemented in Unity. It features a responsive user interface, dynamic parallax, and optimized particle effects, all while maintaining performance standards.  
You can view the completed project via this [(Google Drive Link)](#https://drive.google.com/drive/folders/1AwdAYDF-BIYOzOP71mnuk--grKGzCU31). 

### Key features of the implementation include:
- **Responsive UI Design:** The user interface is fully adaptive, ensuring proper functionality across different screen sizes and aspect ratios while respecting safe zones.  
- **Dynamic Parallax Effects:** Multiple layers of the scene were animated using parallax techniques, creating a rich sense of depth.  
- **Custom Particle Effects:** Unique particle systems were designed and integrated to enhance the atmosphere and visual appeal of the scene.  
- **Performance Optimization:** The scene was optimized to maintain smooth performance, including reduced draw calls, efficient resource usage, and effective asset management.  
- **Seamless Photoshop-to-Unity Transition:** All assets from Photoshop were correctly exported and implemented in Unity with attention to detail and visual consistency.

## Approach

The task was completed using the following approach:

1. **Asset Preparation:** Exported layers and assets from Photoshop while organizing them for smooth import into Unity.  
2. **UI Implementation:** Built the UI in Unity, ensuring responsiveness and compliance with safe zone guidelines.  
3. **Effect Integration:** Created and customized particle systems and visual effects directly in Unity. Used external package "Unity UI Externsions" in order to render Particle System on Unity Canvas.  
4. **Parallax Animation:** Set up and animated layers to achieve a parallax effect, using scripts and Unity’s animation tools.  
5. **Optimization:** Optimized the project for performance, including texture compression, minimal asset loading, and efficient scene management.

### Tools used: Unity 2022.3.48f1, Adobe Photoshop, Jetbrains Rider
